# Batch 201–220

Required uploads now create durable scan records and scheduled work. A validated ClamAV adapter serves production; deterministic synthetic fixtures serve tests. Clean scans permit availability, infection quarantines, and scanner outage never means clean. Operators see safe status and can rescan or remove quarantined artifacts; ordinary teachers cannot override quarantine.

Search remains PostgreSQL backed, school and role filtered, and limited to safe summaries. It does not index credentials, family conversations, recovery data, or scan internals; public verification references do not grant private access. The web shell delays search requests and opens supported results with a fresh authorization check. Large text responses use compression, binary downloads bypass it, and selected authenticated metadata uses private conditional caching. Full offline synchronization is not implemented.

Local PostgreSQL and Docker were unavailable for live integration and Playwright execution. Final checks and GitHub Actions status are recorded in the batch report rather than asserted here.
