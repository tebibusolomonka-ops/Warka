# Batch 161–180

Stabilized the teaching assignment migration, lifecycle fixtures, parent portal test, formatting, and privacy correction browser coverage. Added project memory in this vault.

Backup archives stay outside PostgreSQL. A controlled native `pg_dump` process creates them; size and SHA-256 are recorded. Verification checks metadata, size, checksum, and archive listing. Rehearsals use generated isolated databases and never accept a target from HTTP. A policy models daily/weekly due times and cleanup eligibility without automatically deleting artifacts. Access to backup and operations APIs requires an explicit operator allowlist and current owner membership.

Liveness is separate from readiness. Operational incidents have append-only updates and explicit transitions; maintenance windows communicate planned work. Request logging excludes sensitive bodies and headers. Metrics aggregate by route pattern. Status views and neutral deduplicated alerts are operator scoped. The React workspace and test-only browser adapter cover backup, rehearsal, incident, and teacher-denial journeys.

Local PostgreSQL, Docker, and native backup tools are unavailable in the current environment. Live migration deployment, native backup/restore, and browser execution require CI or a configured integration environment. Backup scheduling and artifact deletion are not yet connected to a production scheduler.
