# Batch 301–320

Coursework formatting from commit 300 was corrected and browser selectors were stabilized. A real PostgreSQL integration suite now exercises explicit coursework mark transfer, including the existing official mark service, school and teacher authority, entry windows, locks, duplicate marks, published results, and transaction rollback. The coursework browser journey remains in Playwright for final CI execution.

`pnpm metrics:code` is the canonical, reproducible tracked implementation file and nonempty line count. It reads Git trees at a selected revision. The commit 300 baseline is 453 files and 59,114 nonempty implementation LOC. See [[Testing]] for exact inclusion and exclusion rules.

Family meetings require a verified linked child and a current class teacher. Teachers publish only school meeting windows, never private calendars. Requests, scheduling, rescheduling, declines, cancellation, and completion preserve append-only history and send preference-aware neutral notifications. Guardian and teacher workspaces use their own scoped API views.

School events have controlled lifecycle, dated plain-text content, audience scopes resolved from current relationships, optional RSVP, and scanned FileAsset attachments. Student and guardian portals show eligible published events. Quarantine blocks download. RSVP history records expressed intent and is never attendance, ranking, engagement scoring, or location tracking.

Targeted unit, API, React, Prisma, and Playwright discovery checks ran during development. Local PostgreSQL is unavailable, so live integration and browser outcomes require the final GitHub Actions run. See [[KnownIssues]] and [[Security]].
